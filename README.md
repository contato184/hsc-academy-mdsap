# HSC Academy · MDSAP Lead Auditor · material do aluno

Páginas HTML interativas do curso MDSAP Lead Auditor (Turma 9), exibidas dentro da Cademi
(learning.academy.hscglobal.com.br) pelo campo **Página incorporada** de cada aula.
Abertas fora da Cademi, mostram a tela "Disponível somente na HSC Academy".

Material de uso exclusivo da HSC Global Group. Todos os direitos reservados.

## PDF editável dos cadernos

Cada caderno de exercícios (M02 a M05) e o Kit de Simulação (M06) têm um PDF editável
(`*_EDITAVEL.pdf`), com caixas de resposta digitáveis e alternativas marcáveis, ligado ao
botão "Baixar PDF editável" no topo da página. Para regenerar depois de alterar um caderno:

    PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers python3 tools/gerar_pdf_editavel.py HSC-MDSAP-M04_Caderno_de_Exercicios_ALUNO.html
